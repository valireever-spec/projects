# Orchestrator: Quick Reference Card

## One-Liner Commands for Systems Integration

### Design Phase
```bash
orchestrator design /path/to/project --framework 8-pillar --generate-plan --effort-estimation
```

### Implement Phase
```bash
orchestrator implement /path/to/project --plan plan.yaml --verify --rollback-on-failure
```

### Troubleshoot Phase
```bash
orchestrator troubleshoot /path/to/project --deep-scan --identify-root-causes --auto-fix
```

### Verify Phase
```bash
orchestrator verify /path/to/project --tests all --coverage-threshold 80 --regression-detection
```

### Validate Phase
```bash
orchestrator validate /path/to/project --framework 8-pillar --strict --generate-report
```

## Full Integration Workflow (5 Steps)

```bash
# 1. DESIGN
orchestrator design ~/projects/project-name \
  --framework 8-pillar \
  --generate-plan improvement.yaml \
  --effort-estimation

# 2. IMPLEMENT
orchestrator implement ~/projects/project-name \
  --plan improvement.yaml \
  --verify \
  --rollback-on-failure

# 3. TROUBLESHOOT (if needed)
orchestrator troubleshoot ~/projects/project-name \
  --auto-fix critical \
  --verify

# 4. VERIFY
orchestrator verify ~/projects/project-name \
  --tests all \
  --regression-detection \
  --coverage-threshold 80

# 5. VALIDATE
orchestrator validate ~/projects/project-name \
  --framework 8-pillar \
  --strict \
  --generate-report

# GENERATE REPORT
orchestrator report --project ~/projects/project-name \
  --type executive --output report.html
```

## Multi-Project Coordination

```bash
# Parallel execution
orchestrator coordinate \
  --projects lotto-sh,crypto-daytrading,skill-creator,network-automation \
  --parallel 4 \
  --report-interval 5m

# With workflow file
orchestrator coordinate \
  --workflow improvement-workflow.yaml \
  --parallel 3 \
  --dependencies respect
```

## Most Common Commands

| Task | Command |
|------|---------|
| Quick audit | `orchestrator design <path> --score 8-pillar` |
| Full design | `orchestrator design <path> --framework 8-pillar --generate-plan` |
| Apply fixes | `orchestrator implement <path> --plan plan.yaml --verify` |
| Find issues | `orchestrator troubleshoot <path> --deep-scan` |
| Fix issues | `orchestrator troubleshoot <path> --auto-fix critical` |
| Run tests | `orchestrator verify <path> --tests all` |
| Validate | `orchestrator validate <path> --framework 8-pillar` |
| Compare | `orchestrator verify <path> --compare-snapshots --before b.json --after a.json` |
| Report | `orchestrator report --project <path> --type executive` |

## Configuration Files Needed

1. **improvement.yaml** - Improvement plan (generated by `design --generate-plan`)
2. **requirements.yaml** - Custom requirements for validation
3. **workflow.yaml** - Multi-project workflow coordination
4. **test-scenarios.yaml** - Custom test scenarios for verification
