# Cum transformi scriptul în video — 100% gratuit, fără experiență

Ești programator și vrei AI gratuit. Ai **două căi**. Începe cu Calea A (cea mai rapidă spre prima postare = testul de 48h).

## Calea A — Fără cod, cea mai rapidă (CapCut Desktop, gratuit)

1. **Voce RO gratuită** — cea mai bună calitate gratuită e **Microsoft Edge TTS** (voci `ro-RO-EmilNeural` bărbat, `ro-RO-AlinaNeural` femeie). Generează fișierul audio (vezi Calea B pasul 1 — durează 10 secunde) SAU folosește TTS-ul din CapCut (mai slab la RO).
2. **Fundal video** — descarcă clipuri verticale gratuite de pe **Pexels.com** sau **Pixabay.com** (căutare: „winter home", „forest romania", „water tap"). Fără drepturi de autor.
3. **Asamblare** — deschide **CapCut** (desktop, gratuit): pune fundalul, importă audio-ul, apasă **Auto-captions** → generează subtitrări RO automat (esențial: 80% se uită fără sunet).
4. **Sursa pe ecran** — adaugă un text overlay la secunda 45 cu numele sursei (ex: „Eurostat, EU-SILC 2024"). Obligatoriu — e regula ta editorială.
5. **Format** — canvas 9:16 (vertical), export 1080p. Gata.

## Calea B — Calea programatorului (automatizabilă, extinde pipeline-ul tău)

Asta se leagă direct de tooling-ul tău existent — output-ul din Export Panel devine input aici.

```bash
# 1. Voce românească gratuită (Microsoft Edge TTS — zero cost, fără cont)
pip install edge-tts
edge-tts --voice ro-RO-EmilNeural --file naratiune.txt --write-media voce.mp3
# voci: ro-RO-EmilNeural (M), ro-RO-AlinaNeural (F)

# 2. Descarcă 2-3 clipuri verticale gratuite de pe Pexels/Pixabay (API gratuit disponibil)

# 3. Asamblare + subtitrări arse cu ffmpeg (sau moviepy dacă preferi Python)
#    - fundal 9:16, audio voce.mp3, subtitrări .srt burned-in, overlay sursă la 0:45
```

**De ce Calea B contează pe termen lung:** dacă un video prinde, poți automatiza pasul script→voce→video și scoți 3-5/săptămână fără efort manual. Asta e exact edge-ul tău („cod + timp"). Dar **nu automatiza înainte să validezi formatul** — fă primele 3 manual, vezi ce prinde.
